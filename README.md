# the-blog

The portfolio blog, built with [Next.js SSG](https://nextjs.org/docs/pages/building-your-application/rendering/static-site-generation) and [Tailwind CSS](https://tailwindcss.com/docs/installation), deployed with [AWS](https://docs.aws.amazon.com/AmazonS3/latest/userguide/website-hosting-custom-domain-walkthrough.html).

## Posts (in-progress)

Stored in `/_posts` as [MDX](https://mdxjs.com/docs/what-is-mdx/) files with [Frontmatter](https://daily-dev-tips.com/posts/what-exactly-is-frontmatter/) support. For more information on MDX in conjunction with Next.js refer to their [configuration guide](https://nextjs.org/docs/pages/building-your-application/configuring/mdx).
